# Click Or Trick – AI Phishing Defense Simulator (Backend)

This repository hosts the backend foundation for **Click Or Trick**, an AI-generated phishing simulator that trains blue-team analysts to spot malicious artifacts across email, SMS, chat, web, and documents. The backend focuses on challenge generation, score tracking, and persistence so the frontend React client can request fresh scenarios each round.

## Features
- Express API with endpoints for challenge generation, sample retrieval, auth, level data, results logging, and health checks.
- 4-dimension randomizer (type, difficulty, target, tactic) producing 700+ combinations before text variations.
- OpenAI integration (GPT-4o mini by default) for live prompts, plus offline fallbacks for demo mode.
- MySQL persistence layer (via mysql2 pool) for storing generated challenges and player results.
- AI critique pipeline: players submit their choice plus an explanation, and the backend returns the correct answer with coaching feedback generated by OpenAI (with heuristic fallback offline).
- JWT-secured authentication plus persistent gamer profiles, level progression, and a live scoreboard sourced from the profiles table.
- Zod-powered validation to guard endpoints.

## Getting Started
```bash
npm install
cp .env.example .env   # provide OpenAI + MySQL + JWT secret credentials
npm run db:init        # creates required tables, users, profiles, and level_progress schema
npm run dev
```
Server listens on `PORT` (default 4000). Set `JWT_SECRET` in `.env` (defaults to `clickortrick-dev-secret`) to sign login tokens. Review `docs/BACKEND_API.md` for detailed request/response formats.

## Authentication & Progression API
- `POST /api/auth/register` – create a user, profile, initial level progression, and return a JWT + profile payload.
- `POST /api/auth/login` – verify credentials, return JWT + profile payload.
- `GET /api/profile` – fetch profile, scoreboard, and current level statuses (requires Bearer token).
- `POST /api/profile/progress` – apply mission verdicts to XP/score/level progression.
- `GET /api/levels` – return ordered level metadata + player-specific lock/completion states.
- Challenge results continue to be recorded through `/api/challenges/results` and automatically update player score/XP when a `playerId` (user id) is provided in the payload metadata.

## API Documentation (ReDoc)
- The canonical OpenAPI spec lives in `docs/openapi.yaml`.
- Generate a polished HTML reference with:
  ```bash
  npm run docs:build
  ```
  This produces `docs/api.html`, which you can open locally or host behind auth for partners.
- You can also import the YAML directly into Postman / Stoplight for mock servers.

## Frontend Mockup
- Location: `frontend/` (React + Vite + TypeScript).
- Run locally:
  ```bash
  cd frontend
  npm install   # already executed during scaffolding
  npm run dev
  ```
- Configure `frontend/.env` with `VITE_API_BASE` (defaults to `https://clickortrick.pgthegod.space/api`) to call the real backend.
- The UI ports every HTML screen from `frontend/HTML_UI/` into TSX (home, login, create account, levels) and exposes a `/game` “API Lab” route that calls `POST /api/challenges/generate` and `POST /api/challenges/results` so backend functionality is verified even while the final game UI is pending.

## Docker Deployment
The root `Dockerfile` builds the React frontend and Node backend into a single container that serves both:

```bash
# build image (optional API override)
docker build -t clickortrick-app --build-arg VITE_API_BASE=https://clickortrick.pgthegod.space/api .

# run with backend secrets supplied via .env
docker run --env-file .env -p 4000:4000 clickortrick-app
```

A helper `docker-compose.yml` is included if you prefer `docker compose up`, still using the root `Dockerfile`.
